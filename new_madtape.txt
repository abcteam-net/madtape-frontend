1. CORE OBJECTIVE & BUSINESS REALIGNMENT
--------------------------------------------------------------------------------
The Madtape platform has been successfully refactored from a simulated client-side 
pricing draft into a production-grade creator community platform for short-form 
AI cinema. 

The new direction establishes trust, transparency, real backend security, 
creator ownership, and simplified monetization. It completely replaces the 
high-overhead, LocalStorage-based credit model with a real Firebase-backed 
database, honest publishing subscriptions, Stripe-disabled fallback alerts, 
and detailed creator workflow disclosures.

2. LEGACY SIMULATIONS & SCAMMY PRICING REMOVED
--------------------------------------------------------------------------------
The following fragile or misleading systems were fully removed from the codebase:
  * Madness Credits: Removed credit-deduction math, currency tokens, and credit 
    packs.
  * 40-Minute Cooldown: Deleted the execution cooldown period, replacing it 
    with standard monthly plan upload limits.
  * Fake Payment Simulator: Removed the mock credit card form validation that 
    faked subscription and wallet upgrades.
  * LocalStorage Billing: Terminated browser-side localStorage caching for plans 
    and credit balances to prevent client-side authorization bypasses.
  * Unverified Action Entries: Cleaned up other actions like "Upscale" and 
    "Extend" to render as clear "Coming soon" elements.

3. SIMPLIFIED CREATOR PLANS & OPTIONAL GENERATION PACKS
--------------------------------------------------------------------------------
Subscription packages are now focused on tools and publishing limits:
  * Free ($0/mo)       : Upload 5 films/mo, share workflows, community feed access.
  * Creator ($15/mo)   : Upload 20 films/mo, metrics dashboard, Creator badge.
  * Pro ($39/mo)       : Unlimited uploads, challenge priority index, priority support.

Video generation is decoupled into optional pricing options:
  * Pay-As-You-Go      : $0.10 USD per 5-second video render.
  * Creator Pack ($29) : 50 videos / month, 5s outputs, up to 1080p.
  * Studio Pack ($79)  : 200 videos / month, 5s outputs, Seedance 2.0, API access.

4. FIREBASE SDK & DATABASE ARCHITECTURE
--------------------------------------------------------------------------------
  * NPM SDK Installation: Installed modular Firebase SDK v10 (firebase) and 
    configured app initializations in src/firebase-config.js.
  * Database Security (firestore.rules): Configured collection rules in the root:
    - Users can read all docs, edit only their own /users/{uid} document.
    - Creators can create, edit, or delete only their own /films/{filmId} items.
    - Blocked client-side creation of /donations/ records to secure billing.
  * Stored Profile Fetch: Authentication state listeners in src/main.jsx load 
    user profiles directly from Firestore onAuthStateChanged. If no record 
    is found, the system initializes a free tier document in Firestore.

5. STRIPE CHECKOUT & CONNECTIONS (DISABLED MODE)
--------------------------------------------------------------------------------
  * Payment Flag: Set STRIPE_ENABLED = false in src/platform-data.jsx.
  * Fallback Notices: Attempting to subscribe to a plan, purchase a pack, or 
    onboard to Stripe Connect opens a clean notification dialog:
    "Payments are coming soon. Real Stripe Checkout transactions are disabled 
    during this beta preview."
  * Real Code Foundations: Stripe billing logic and Connect webhook endpoints 
    remain in the codebase to facilitate a fast toggle to production.

6. UPLOAD STEPS & WORKFLOW SHARING
--------------------------------------------------------------------------------
  * Workflow HUD: Film detail pages (src/page-profile-video.jsx) now display a 
    detailed workflow layout detailing:
    - Tools Used (rendered as clean visual capsules, e.g. Midjourney, ElevenLabs)
    - Production Steps (displayed as a numbered timeline guide)
    - Production Time (e.g. "5 hours") and estimated cost (e.g. "$1.80 USD")
  * Stepper Form: The Upload Page collects workflow metadata and contains a 
    mandatory checkbox for content ownership confirmation.

7. SIDEBAR AUDIENCE MONETIZATION (💛 TIPPING)
--------------------------------------------------------------------------------

    sheet detailing that 95% of tips go directly to the creator (5% platform fee).

    account balances.
